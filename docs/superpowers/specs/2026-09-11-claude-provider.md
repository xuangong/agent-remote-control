# Claude Provider for Agent Host

Add a dedicated Claude Code adapter alongside Codex in the existing multi-provider Host. Keep native interpretation in `agent-provider-claude`; the Provider SDK, Remote protocol 1.4.0, Relay, and renderer retain their contracts. Use the official `@anthropic-ai/claude-agent-sdk` pinned to 0.3.247 and validate against Claude Code 2.1.247.

Use a persistent streaming-input Query for each opened session. Host lifetime owns these queries, independently of browser/uplink lifetime. Create a UUID accepted by the native SDK, initialize without sending a model prompt, and preserve that identity when resuming. Read persisted catalogs/history through official SDK APIs in an environment-isolated helper process. Never change global process environment to switch Claude configuration roots. Honor the user's native user/project/local configuration in normal operation; tests supply an isolated configuration root and a deterministic local Messages endpoint.

Project user messages, streaming assistant text, reasoning, tool calls/results, usage, compaction, and turn completion/failure/cancellation into existing observations. Preserve stable source keys for historical entries and suppress streamed/final-message duplication. Nested agent messages must not impersonate the root conversation. Tool permission requests and AskUserQuestion map to existing interactions; only one-time approvals are offered. Unsupported native child navigation, resource reads, commands, and mid-turn queue/steering are not advertised. Plan mode is accepted at creation and can be toggled through native permission controls; leaving plan mode still uses native tool approval.

Add `AGENT_HOST_PROVIDERS=codex,claude` for both providers, or `claude` for Claude alone. Keep `codex` as the backward-compatible default. `AGENT_HOST_CLAUDE` selects the executable and `AGENT_HOST_CLAUDE_HOME` selects the native configuration root. Validate explicitly selected executables before registering; never silently advertise unavailable providers. Retain provider-scoped catalogs, identities, failures, and re-pair behavior.

Validate adapter behavior, invalid interaction answers, interrupted/disposed permissions, persistence and history, plus real WebSocket Host registration/routing/re-pair with both providers. Run the actual Claude binary against a deterministic loopback server for create/chat/tool approval/resume, and the existing Codex regression suites with their pinned executable. Update compatibility metadata and run update/check after reviewed changes. Preserve main, existing worktrees, services, and credentials. Keep the feature local unless asked to publish.
