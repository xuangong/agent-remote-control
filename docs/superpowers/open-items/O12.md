# O12: Slow-test enforcement is opt-in

- Found in: M0
- Owner step: M12
- Status: closed

## Item

Slow-test enforcement is opt-in (`ARC_SLOW_TEST_ENFORCE`). It becomes the default once the allowlist is justified entry by entry

## Status

closed (open-items sweep): enforcement is the default (`ARC_SLOW_TEST_ENFORCE=0` only lists). Before failing a run the reporter runs the test's file once more alone on one worker and fails only if the test is over 1 s again, a retry for timing only (in the loaded gate, 3 tests over 1 s passed the re-measurement and 1 failed it twice). The allowlist refuses an entry without a reason and names allowlisted tests that ran under 300 ms. Allowlist 71 to 11 entries: Cloudflare `storage-incremental` (3, a commit-cost measurement at operating size), journal 200,000-item paging and prepend (2, a spread-argument limit needs that size) and 6 whole-App tests (O18)
