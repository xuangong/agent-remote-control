# OpenCode 2.x Integration Implementation Plan

> **For agentic workers:** Use subagent-driven development for the independent Host and native projection changes. Keep builds serial with tests that consume package output.

**Goal:** Let a Host with official OpenCode 2.0.25 discover, start, and share its native sessions through the existing Session View.

**Architecture:** Replace the obsolete 1.x native API integration with the official 2.x Promise client. Native protocol interpretation stays in the OpenCode adapter; lifecycle and executable discovery stay in the Host. Public normalized events and Session View behavior remain provider neutral.

**Tech Stack:** TypeScript, `@opencode/client` 2.0.25, HTTP/SSE, Vitest, isolated native CLI tests.

**Spec:** User decisions in this task: support the installed official `opencode v2.0.25`; old OpenCode support is unimportant. Preserve existing processes and sessions. Connection stages must remain visible on mobile while Ready stays hidden. A rejected native attach must provide an actionable take-control entry.

## Native Evidence Boundary

OpenCode 2.0.25 does not persist its experimental session event log by default.
Its public message history does not retain the complete historical system
instruction selection required by the prepared-input contract. Current settings
cannot establish what settings an earlier input used. Handoff is therefore
explicitly unavailable before candidate creation or prepared dispatch. Enabling
it requires a separately reviewed recording mechanism; no such mechanism is
included in this migration.

The disabled capability does not start profile, global ancestry or inbox reads
for ordinary sessions. The unreachable empty-session evidence path and its
observation machinery are removed; ordinary message reconciliation is independent.
Interaction completion and failed native settings reads explicitly schedule the
ordinary state refresh.

Ordinary input reconciliation has a narrower proof: the exact native user ID and
content, followed immediately by a native assistant record in native sequence.
Intervening controls, other inputs, unmatched attachments or missing records keep
the result unknown. Neither a lost acknowledgement nor process recovery causes
an automatic resend. Transformed native image bytes may prevent this strict
match; the adapter does not substitute weaker evidence.
