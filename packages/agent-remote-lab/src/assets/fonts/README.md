# Tracking count font

`baloo-2-800-digits.woff2` is the Baloo 2 ExtraBold (800) digit subset, served by Google Fonts on 2026-09-20. It is bundled locally for consistent rounded numerals without third-party runtime requests.

Source: https://fonts.googleapis.com/css2?family=Baloo+2:wght@800&text=0123456789&display=swap

Only U+0030–U+0039 is included. The SIL Open Font License is distributed at `public/assets/fonts/baloo-2-OFL.txt`.
