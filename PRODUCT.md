# Product

## Register

product

## Users

Developers exploring remote agent conversations on a desktop in a normally lit workspace, with occasional mobile checks. They need to find a native session, continue its conversation, and inspect protocol evidence without leaving the workbench.

## Product Purpose

Agent Remote Control is an independent home for provider adapters, the Remote protocol, relay, shared renderers, and a daily session workbench. Session discovery and conversation are primary; Trace and Replica inspection are available when needed.

## Brand Personality

Calm, precise, practical. Use familiar controls and concise English interface text.

## Anti-references

Avoid marketing dashboards, decorative metric cards, raw protocol objects as the default conversation, and dense debugging controls competing with chat.

## Design Principles

- Keep conversations readable and discovery easy to return to.
- Preserve loaded content and drafts across navigation and interrupted connections.
- Make native session identity stable and opening the same session reusable.
- Surface uncertain outcomes explicitly and never replay a message automatically.

## Accessibility & Inclusion

Use native form controls, visible focus, semantic labels, keyboard navigation, and responsive supporting drawers. Respect reduced motion.
