# O50: With the managed terminal, the journal-served page is not told that a terminal holds the session

- Found in: M6 (exploration)
- Owner step: owner
- Status: open

## Item

With the managed terminal (`agent-remote-controller claude --resume <id> --take-over -p`), the journal-served page is not told that a terminal holds the session: no `session_control` frame arrives while the terminal runs, and the page learns only when its next send is refused (`native_session_owned`). The refusal toast then covers the conversation's own "Interrupt & take over" in the rightmost tile, and pointing at the button pauses the toast's auto-dismiss, so the button cannot be clicked until the toast is closed (`.tmp/m6/claude-after-send.png`)
