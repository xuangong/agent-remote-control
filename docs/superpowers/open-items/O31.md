# O31: WebKit with the iPhone profile empties the composer after a synthetic Shift+Enter

- Found in: M15
- Owner step: owner
- Status: closed

## Item

WebKit with the iPhone profile empties the composer after a synthetic Shift+Enter in the component test of pasted line breaks

## Status

closed (71a0505a): a product defect on iOS with a hardware keyboard, not a test assumption. ProseMirror takes Enter on iOS before `handleKeyDown` and replays it without Shift about 200 ms later, so Shift+Enter sent the draft. `ComposerEditor` reads Shift from the DOM keydown, turns the paragraph input after Shift+Enter into a line break and drops an untrusted Enter within 400 ms. 2 unit tests (3 mutations caught); the component test runs again on `webkit-mobile`
